# Social Carousel Automation Skill (Claude Instagram Agent Steal)

## Brand Style
- **Voice**: Technical but human, no fluff, anti-slop
- **Tone**: Direct, evidence-first, mildly critical (Conviction > Warmth per AA Personality Bench)
- **Mascot**: ThumbGate logo with cyan accent (#22d3ee)
- **Fonts**: Inter for headlines, monospace for code/snippets
- **Colors**: Dark background (#0a0f1a), cyan accent (#22d3ee), green success (#56e39f)

## Formatting Rules
1. Hook slide = one sentence + specific number + ALL-CAPS power word + 👉 emoji
2. Body slides = large number + short headline + 2-3 plain sentences + screenshot + 2 verified stat boxes
3. Every number must be verifiable at creation time — if not, omit it
4. End every carousel with keyword + link to free guide
5. Never publish without explicit human approval ("send it")

## Guardrails
- Never claim unverified metrics
- Never use stock photos — all visuals from live site or code
- Always verify GitHub stars, MIT license status, version numbers at creation
- ECI corporate domains (@ecisolutions.com, @ecinexus.com, @eci.com) blocked

## Per-Platform Variations
- **LinkedIn**: Add "Link in comments" on final slide (no comment-to-DM automation)
- **X/Twitter**: 280-char caption, 2-3 hashtags
- **Bluesky**: Same as X but with longer thread context
- **Threads**: Instagram-style + Facebook cross-post
- **Hacker News**: Show HN format, link to GitHub repo
- **Reddit**: r/programming format, discussion prompt at end
- **BiggerPockets**: REI-specific framing, "prevention > cure" angle
- **Skool**: Community teaching format, weekly pattern drop
- **Zyvop**: Single actionable insight, link to proof

## Feedback → Skill Loop
Every correction from human review MUST be appended to this file with:
- **What was wrong**: specific description
- **What to do instead**: concrete rule
- **Timestamp**: when the rule was learned

## Social Media Schedule
- Monday: Steal of the week (architecture pattern)
- Tuesday: Deep dive (technical explanation)
- Wednesday: Customer story or proof
- Thursday: Tool comparison or benchmark
- Friday: Team culture / hiring
- Saturday: Weekend reading (curated)
- Sunday: Weekly recap

## Auto-QC Checklist (Run Before Publishing)
- [ ] All screenshot images render without errors
- [ ] Step numbers are sequential and match content
- [ ] No copyright characters (©, ®, ™ in body)
- [ ] All numbers verified against live sources
- [ ] Caption fits platform character limits
- [ ] 5 relevant hashtags included (Instagram/LinkedIn)
- [ ] Keyword + lead magnet link in final slide
- [ ] Mascot/logo appears on hook slide only
