# Daily Memory: 2026-06-07

## AI Coding Project Management

- June 2026 operating model: use spec-driven development plus eval-driven
  verification plus manager-of-agents orchestration. The repeatable hierarchy is
  `use case -> milestone -> phase -> agent-ready issue -> PR proof packet`.
- GitHub Issues/Projects/PRs remain the default source of truth for ThumbGate.
  Linear is a later upgrade when issue volume and agent delegation justify a
  second PM system.
- Each AI-coded task should declare use-case bucket, milestone, phase, risk
  tier, rollback path, token-cost budget, and deterministic proof before work is
  treated as complete.

## Token Burn And Delegation

- Token burn is not a vanity metric. Use it as a feedback loop: compare tokens
  and estimated cost against merged PRs, fixed failures, customer evidence, or
  revenue movement.
- For long-running agent fleets, stop or split work when token burn rises
  without new evidence. The dashboard token-burn panel and `scripts/token-burn.js`
  are the canonical local review path.

## Packaging Lesson

- If a packaged runtime file imports a new local module, the module must be in
  `package.json:files` and package-boundary ratchets must be bumped together
  with measured `npm pack --dry-run --json` evidence. On 2026-06-07,
  `scripts/dashboard.js -> scripts/token-burn.js` proved this: local tests were
  green, but CI correctly failed until the npm package shipped the dependency.
