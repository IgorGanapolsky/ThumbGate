## Comment starters (non-promotional, high-signal)

Use these as replies on Reddit/LinkedIn/Threads/Bluesky when someone describes agent failures, workflow drift, or unsafe tool calls.

1. “What’s the *one* mistake you’ve seen repeat most often (and how are you currently catching it)?”
2. “Do you have a pre-action check anywhere, or are you relying on prompts + hope?”
3. “Is the failure mostly context drift, tool misuse, or missing approval boundaries?”
4. “If you had to write a 1-sentence rule for that failure, what would it be?”
5. “Where in the workflow does the mistake first become *detectable* (before damage)?”
6. “Are you logging the bad runs, or are they getting lost in chat history?”
7. “Does the agent fail the same way across tools (Claude Code/Codex/Cursor), or only one runtime?”
8. “If you could block one tool call category tomorrow, what would you block first?”
9. “How do you verify you fixed it (proof run / regression check / replay)?”
10. “Is this happening on a single workflow owner machine, or does it show up across a team?”
