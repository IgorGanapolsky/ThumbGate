### Short Pitch

ThumbGate is an open-source agent governance layer for coding agents and enterprise AI workflows. It captures thumbs-up/down feedback, turns repeated failure patterns into durable lessons and prevention rules, and checks risky tool calls before they execute. It works with Claude Code, Cursor, Codex, Gemini CLI, Amp, Cline, OpenCode, MCP-compatible agents, and local dashboards.

The product sits at the intersection of two current enterprise AI trends: persistent memory systems and agentic enterprise governance. Memory stacks help agents remember; ThumbGate asks the next operational question: should this remembered failure block the next action before it touches code, data, CI, payments, or production?

### 500-Word Submission Draft

AI teams are moving quickly from chatbots to agents that edit code, run shell commands, call APIs, create pull requests, trigger deployments, and touch customer systems. That shift creates a new operational problem: the same AI mistake can repeat across sessions, agents, and machines unless the organization has a way to convert feedback into enforceable controls.

ThumbGate is an open-source pre-action gate layer built for that problem. It captures human feedback such as thumbs up, thumbs down, and specific correction notes. Those signals become structured lessons, prevention rules, and audit records. Before an agent executes a risky action, ThumbGate can check the action against prior failures, policy gates, context requirements, and proof expectations. If the action matches a known bad pattern, it can block before the tool call runs.

This is different from ordinary agent memory. Memory helps the agent recall context. ThumbGate adds enforcement. A remembered lesson such as "do not claim a release was published before checking npm" becomes a concrete gate that can stop the next premature publish claim or risky command. That distinction matters for enterprise adoption because AI agents increasingly operate around code, regulated data, billing systems, customer communications, and production workflows.

ThumbGate runs local-first through CLI hooks, MCP tools, and dashboard surfaces, with support for Claude Code, Cursor, Codex, Gemini CLI, Amp, Cline, OpenCode, and MCP-compatible agents. Teams can use it to prevent repeated migration failures, unsafe force-pushes, unverified release claims, secret exposure, destructive database operations, and low-evidence deploys. The project also includes ThumbGate Bench, a deterministic scenario suite for proving which actions are blocked, allowed, or routed for review.

The broader category is becoming clearer: enterprise agents need a context brain, a memory layer, and an enforcement layer. HBR's recent "agentic enterprise" framing points to a real problem: fragmented workflows and hidden context stop agents from understanding how decisions, documents, and systems relate. Memory OS and similar projects show why structured memory, hybrid retrieval, and context injection matter. ThumbGate complements that movement by turning trusted lessons into pre-action controls.

The result is simple: a human correction should not disappear into chat history. If an AI agent gets a thumbs down for a costly mistake, the organization should be able to prevent the same mistake from executing again.
