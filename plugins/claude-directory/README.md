# ThumbGate for Claude

This folder is the ThumbGate plugin submitted to the Claude plugin directory. It holds only Markdown, JSON and the icon, so it installs nothing on your computer:

- **Hosted ThumbGate server** at `https://thumbgate.ai/mcp`: capture feedback, search lessons, list prevention rules and gate stats.
- **Skills:** capture feedback, turn a mistake into a rule, list rules, see what was blocked, check the wiring, approve a protected change.

Local enforcement (the PreToolUse hook that blocks a known-bad tool call before it runs) comes from the full ThumbGate package. Install it by following https://thumbgate.ai/guide.

Data: the hosted server stores the feedback and rules you send it. Privacy policy: https://thumbgate.ai/privacy

Docs: https://thumbgate.ai/guide
