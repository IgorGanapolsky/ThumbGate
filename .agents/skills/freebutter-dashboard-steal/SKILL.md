# Freebutter Dashboard — Value-Storytelling FORMAT Steal

> Source: [freebutter.ai](https://freebutter.ai) — "I model the economics. Then build the system."

## The FORMAT (What to Steal)

Freebutter embeds **live dashboard screenshots** directly in the page hero — not behind a
login or CLI. The dashboard alt text reads: *"The live Freway performance dashboard:
$22,513 recovered, 50 engaged checkouts, 50% win rate."*

### Pattern: Dollar-Value Storytelling

Every metric on the Freebutter dashboard answers: **How much money did we make / save?**

| Freebutter Pattern | ThumbGate Equivalent |
|---|---|
| "$22,513 recovered, 50 engaged checkouts" | "$X saved from blocked agent errors, Y gates today" |
| "Cost per lead, conversion at each stage" | "Errors prevented, gates triggered, cost per denial" |
| "Commission per villa < ads cost → walk away" | "License cost vs. prevented double-charges" |
| Cove Estates: $6,125 media cost vs. $245,000 villa | "Before/After: agent cost with vs. without ThumbGate" |

### Pattern: Before/After Proof

Freebutter leads with the **outcome** (revenue recovered) before explaining the **mechanism**
(checkout automation). The Cove Estates case study frames it as an advisory decision:
"Commission per villa < ads cost — walked away."

### Pattern: Portfolio View

Products (Freway, SoulHunt, Freebot, OneShot) each get their own dashboard showing
**different metrics** for different workflows. No single monolithic dashboard.

## What NOT to Clone

- Do NOT clone Freebutter's checkout agent (Freway) — that is their core product, not a dashboard pattern.
- Do NOT clone their "Start a project / Book a 15-min triage call" funnel — ThumbGate is self-serve ($19/mo).
- Do NOT copy their commission-split model — that is specific to real-estate acquisition.

## Application to ThumbGate

1. **Hero dashboard screenshot** showing "$X saved from prevented errors, Y gates triggered today"
2. **Before/After proof section** — "Agent cost with vs. without ThumbGate" using concrete dollar amounts
3. **Per-agent-workflow dashboards** — e.g., "Claude Code gates", "Cursor coding gates", "AWS CLI gates"
4. **Lead with prevented-cost, not feature specs** — replace `<0.5ms` with "$/hour of engineering firefighting saved"
