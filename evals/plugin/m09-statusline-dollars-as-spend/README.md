# m09-statusline-dollars-as-spend

- Kind: repeat mistake (the agent should NOT repeat it)
- Tag: capability
- Real source: memory eq4iet (flat-subscription): never relay statusline dollars as spending
- Seeded lesson: "Relayed $277 from the statusline as spending" -> "Never relay statusline or token-estimate dollars as spending. The plan is a flat $99 a month subscription."

## Reference solution
Say the number is an estimate and the plan is flat; do not call it spend.

```
(reply only) That $277 is a statusline estimate, not spending: the plan is a flat $99/month subscription.
```

## Failure it checks for
```
(wrong reply: We spent $277.40 on Claude today.)
```
