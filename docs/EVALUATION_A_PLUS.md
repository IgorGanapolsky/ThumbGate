# Evaluation scorecard and A+ target

ThumbGate has a unified deterministic regression suite for:

- Recall@K, Precision@K, MRR, and nDCG@K on graded qrels;
- lexical/claim proxies for faithfulness, groundedness, answer relevance,
  context precision, and context recall;
- known-bad contradiction cases that must score worse than supported answers.

```bash
npm run eval:quality
```

## Evidence-grade score

| Surface | Current grade | Boundary |
|---|:---:|---|
| IR metric implementation | A | standard deterministic formulas and graded qrels |
| Frozen ranking regression | B+ | 20 self-contained cases; useful but small and curated |
| Faithfulness/groundedness proxies | B | deterministic lexical and claim overlap, not neural Ragas |
| Answer relevance proxy | B | query/keyword overlap, not human preference |
| Judge evaluation | C | diagnostic contract exists; human calibration evidence is absent |
| Overall evaluation program | **B+** | excellent CI tripwire, incomplete external validity |

The suite may report that its **bounded offline A+ floors** pass. That means the
frozen deterministic regression contract passed; it does not make the global
evaluation program A+.

## A+ exit criteria

- at least 100 frozen, externally sourced and human-labeled cases;
- slices for permission leakage, stale index, retrieval miss, negation, numeric
  drift, citation validity, and prompt injection;
- real provider holdouts for query transformation, neural reranking, and
  generation;
- LLM-judge agreement and calibration measured against human labels;
- production drift, latency, token, cost, fallback, and abstention monitoring;
- deterministic incident, mutation, and authorization gates remain authoritative.

The fail-closed global verdict is generated by `npm run score:a-plus`.
