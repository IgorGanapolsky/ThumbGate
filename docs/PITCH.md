# ThumbGate

ThumbGate captures feedback and runs configured pre-action gates where AI agents execute work. The MIT local CLI is free. Self-serve Pro adds recall, dashboard, adapters, and exports.

Start with `npx thumbgate init`, compare [current plans](https://thumbgate.ai/pricing), or open [Pro checkout](https://thumbgate.ai/checkout/pro). Pro is a software subscription; it does not include workflow implementation services or generally available hosted team sync.

Supported hook integrations can enforce configured rules. Advisory integrations do not guarantee blocking. Claims about deployment and compatibility require the [verification evidence](VERIFICATION_EVIDENCE.md); commercial claims follow [Commercial Truth](COMMERCIAL_TRUTH.md).
