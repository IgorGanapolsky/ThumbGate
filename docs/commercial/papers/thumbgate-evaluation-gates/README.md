# Preprint: How We Know Pre-Action Gates Work

ArXiv-oriented source for ThumbGate evaluation framework.

## Build

```bash
cd papers/thumbgate-evaluation-gates
tectonic main.tex
# or: pdflatex main.tex && pdflatex main.tex
```

## Submit

1. Register at https://arxiv.org/user/register (author: Igor Ganapolsky, email iganapolsky@gmail.com)
2. Category: cs.SE (primary), cs.AI (cross-list)
3. Upload `main.tex` (and generated `.bbl` if any) as a .tar.gz of sources
4. After announcement, index on HF: https://huggingface.co/papers/submit or visit `hf.co/papers/<arxiv-id>`
5. Claim authorship on the HF paper page; link Space + dataset in cards
