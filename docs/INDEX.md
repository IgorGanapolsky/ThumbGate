## Writing rule (keep the root README small)

1. **Root README** = value prop, install, agent matrix, scope, pricing, short how-it-works, links.
2. **This index + specialist docs** = architecture depth, export APIs, regulated playbooks, GTM.
3. Do not re-expand the root README with full CLI manuals, DPO curl walls, or multi-page sales funnels. Link here instead.
