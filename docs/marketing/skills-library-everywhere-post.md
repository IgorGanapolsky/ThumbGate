# LinkedIn Post: Skills Library Enforcement

**Title:** Skills libraries need enforcement

**Body:**
Skills libraries tell agents how a team works. They help Cursor, Claude Code, Codex, Gemini CLI, and MCP agents share context instead of improvising from scattered docs.

The missing layer is enforcement.

When the same correction repeats, it should stop being tribal knowledge. Capture it, promote it into a reusable rule, and make it a pre-action gate before the next risky tool call runs.

That is ThumbGate's lane: feedback -> rule -> pre-action gate.
