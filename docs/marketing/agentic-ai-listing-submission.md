### Tagline

### Short Description

ThumbGate turns thumbs-down feedback and prior agent failures into pre-action checks. It runs beside Claude Code, Cursor, Codex, Gemini CLI, Amp, OpenCode, ChatGPT Actions, CI, and MCP-compatible agents to block risky commands, edits, deploys, publishes, and PR actions before they execute.

### Long Description

ThumbGate is a local-first agent governance layer for teams using AI coding agents on real repositories. When an agent makes a mistake, the operator captures a thumbs-down with context. ThumbGate stores the lesson, promotes repeated patterns into prevention rules, and checks future tool calls before they run.

The enforcement point is before execution, not after review: shell commands, file writes, git actions, deploys, publish commands, API calls, and other risky tool calls can be blocked, approved, or logged based on policy and learned failure patterns. This helps teams prevent repeated agent mistakes across sessions, models, and agent surfaces.

ThumbGate supports Claude Code, Cursor, OpenAI Codex, Gemini CLI, Amp, Cline, OpenCode, ChatGPT Actions, CI, and MCP-compatible runtimes. The free local CLI is the adoption path; paid Pro and Enterprise Pilot surfaces add hosted dashboards, exports, shared lesson databases, org review views, and workflow hardening support.

### What It Does

- Converts explicit thumbs-up/down feedback into durable local lessons.
- Blocks repeat risky actions before tool execution through PreToolUse checks.
- Supports MCP, CLI hooks, Codex plugin metadata, Claude/Cursor/Gemini/Amp/OpenCode adapters, and CI gates.
- Tracks blocked actions, prevention rules, and feedback history for review.
- Offers local-first operation by default, with hosted Pro and Enterprise Pilot options for dashboards, exports, shared lessons, and workflow rollout.

### Best-Fit Users
