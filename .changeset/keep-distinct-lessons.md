A new lesson that is only worded like an earlier one no longer replaces it. Before, three lessons that differed in one detail (which page of a form was not checked) were merged into one memory row that kept only the last text. Now only an identical lesson merges. A similar lesson keeps its own row, the earlier row keeps its own text, and the earlier row's repeat count still goes up so a repeated mistake is still promoted to a rule.
