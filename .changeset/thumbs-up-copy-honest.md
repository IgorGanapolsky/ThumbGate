Say what a thumbs-up actually does. README gets a "What a 👍 and a 👎 do" table with an example; the guide, compare and learn pages, the homepage loop diagram, SKILL.md and the Codex plugin FAQ stop saying a thumbs-up "reinforces" behavior, widens a rule back toward allowing, or teaches rules. In the released version a thumbs-up with context is saved as a success lesson and counted; it does not create, loosen or lift a check. The Allow and Warn verdicts use ✅ and ⚠️ so they are no longer confused with the thumbs.
