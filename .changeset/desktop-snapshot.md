New `thumbgate desktop-snapshot [--json] [--limit=N]` prints one read-only JSON snapshot (`thumbgate.desktop-snapshot/v1`: blocked and warned totals, recent blocks, recent thumbs-downs, rules, plan) for desktop and menu bar apps. `adapters/claude-desktop-app/` adds ThumbGate Desktop, a Claude artifact you install as a Mac or Windows app that reads it, plus a learn page at `/learn/claude-artifact-desktop-apps`.
