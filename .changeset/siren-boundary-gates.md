Three new default gates from Anthropic's Siren sandbox-escape study: `cloud-metadata-credential` blocks calls to cloud instance-metadata services, `container-host-control` asks a person before an agent uses a container engine socket, a node control API, or starts a container with host-level access, and `app-store-review-withdraw` blocks withdrawing an App Store review submission unless the owner approves that exact action once.
