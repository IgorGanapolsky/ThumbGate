Fix `getLessonStats()` (the "Stats: N up / N down" line shown after every `capture-feedback` CLI run) to only count entries with a real, non-empty `triggerMessage`. Discovered 2026-07-23: 97.7% of this project's own lessons-index (4507 of 4613 entries) were synthetic — auto-generated by internal harnesses (async job runner, proof scripts, dogfood tests) with empty triggerMessage and placeholder text like "SUCCESS: positive pattern 0" — not genuine human feedback. The displayed count was overwhelmingly internal telemetry, not user signal.
