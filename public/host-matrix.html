Enforcement strength

Hard pre-tool-use: claude-code, codex, gemini, forge.

Cursor: hard for shell only, advisory for file edits and MCP, and its shell hook fails open on error.

Advisory: cline, opencode.

Feedback capture only: amp.

Caveats

A fresh install needs its runtime cached first, or the hook fails open.

ThumbGate is a policy and observability layer on the tool-call path. It is not a sandbox, firewall, or containment boundary, and it does not block every call.

Denial is rule-specific. rm -rf ~/ and root are denied by rm-rf-home-or-root. rm -rf ./src is not denied. A staged secret at commit time is not denied, only warned on task scope.
