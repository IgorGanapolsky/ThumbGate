Which agents ThumbGate hard-stops, and which only warn

TL;DR: Claude Code and Cursor shell commands are hard-stopped by a hook. Cline, OpenCode and Amp have no hook, so they warn or capture feedback only. Codex and Gemini CLI are untested.

This table is generated by npm run compat:matrix from real runs through each agent's hook path, and a test fails the build if the page differs from a fresh run. A "yes" means the hook denied at least one gate's command in that run. "Fails open" means that when ThumbGate itself errors, the command still runs.

Limits: a denial is the default configuration in a clean home folder. Text typed into a chat window or web page is never seen by a hook. Gates that need project state have no stateless denial to run and are not counted. The per-gate table is in docs/host-compatibility.md.
