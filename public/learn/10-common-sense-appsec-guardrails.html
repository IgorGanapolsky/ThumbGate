The 10 Deterministic AppSec Invariants

  1. Unauthenticated Route Exposure (APPSEC_01): Blocks internal and administrative route registrations lacking verified authentication middleware.
  2. Hardcoded Credentials & API Keys (APPSEC_02): Strict regex matching catches AWS keys, OpenAI tokens, JWTs, and private keys before execution.
  3. Permissive CORS Wildcards (APPSEC_03): Prevents wildcard CORS origins paired with credentials: true, eliminating cross-origin session hijacking.
  4. SSRF Egress to Private/Cloud Metadata (APPSEC_04): Blocks outbound requests to 169.254.169.254, loopback, and RFC 1918 subnets at the runtime boundary.
  5. Unparameterized Dynamic Injection (APPSEC_05): Enforces parameterized database queries and structured execFile arguments.
  6. Arbitrary Path Traversal (APPSEC_06): Interdicts relative directory traversal sequences (../) in file system calls.
  7. Telemetry PII & Header Leakage (APPSEC_07): Sanitizes log payloads to prevent dumping authorization headers, cookies, or user PII into monitoring sinks.
  8. Multi-Tenant IDOR Scope Enforcement (APPSEC_08): Mandates explicit tenant_id predicates on all tenant-isolated data queries.
  9. Executable File Upload Protection (APPSEC_09): Restricts upload destinations to ensure scripts (.sh, .php, .exe) cannot be written into public web asset roots.
  10. Insecure Deserialization & Eval Interdiction (APPSEC_10): Blocks dynamic eval() and unsafe object deserialization.
