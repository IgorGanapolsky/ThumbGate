Learn / Claude artifacts as desktop apps

Claude artifacts are now desktop apps. Put your agent's guardrails in the menu bar

4 min read · For developers running Claude Code and other coding agents

TL;DR: On November 24, 2026 Anthropic started letting Claude users install an artifact as a Mac or Windows app, in beta. An installed app can ask for a menu bar item, notifications, a global shortcut and, if you allow it, access to your computer. ThumbGate Desktop uses that to show what your gates blocked, your recent thumbs-downs and the rules they became, with a block count in the menu bar. Enforcement stays where it was, in ThumbGate's PreToolUse hook.

What Anthropic shipped

These points come from Anthropic's own help article and release notes, linked below.

  • Install as app. Open an artifact in Claude for Mac or Claude for Windows, version 6.28899.0 or later, and choose Install as app from the title menu, the right-click menu or Share. It gets its own window and icon, in a Claude Apps folder on macOS or the Start menu on Windows.
  • Beta on every plan. Free, Pro, Max, Ultra, Team and Enterprise. On Team the feature is on but full computer access is off until an admin turns it on. On Enterprise an owner turns the whole feature on.
  • Permissions you approve one at a time. Notifications, keyboard shortcuts in other apps, floating over other windows, a menu bar or tray item, and full access to the computer. An Allow covers one version, so an update asks again. A Don't allow is kept.
  • Not offline. Opening an app needs an internet connection and a signed-in Claude Desktop session. Apps keep the artifact's access to Claude and your connectors.
  • Limits. No Linux, web or mobile. Docs, Slides and Sheets template artifacts, legacy artifacts and Cowork live artifacts cannot be installed. Organizations with HIPAA-ready configurations cannot use it.

Why this matters for agent guardrails

A pre-action gate works in the terminal, where the agent runs. That is also why most people forget it is there. When a gate blocks a force-push at 2 AM inside a background session, nobody sees it until they read a log.

A desktop app changes where that information lives. A count in the menu bar and a notification when something is blocked make the guardrail visible while you are in your editor, your browser or a meeting.

Anthropic's own safety note applies here too: an app with full access "can run any program and read, change, or delete your files," and Anthropic does not review apps before you install them. So a guardrail companion should ask for as little as it can and say exactly what it runs.

ThumbGate Desktop: what it does

  • Menu bar count. The number of tool calls ThumbGate has blocked, with the last block and your rule count in its menu.
  • An alert on each new block. When the blocked count goes up between checks, you get a notification with the reason.
  • The story behind each rule. Recent blocks, recent thumbs-downs, which of them became rules, and your active prevention rules.
  • A shortcut. Alt-Shift-G brings the window up and refreshes it.
  • Plan status. Free installs see what Pro adds. Pro installs see no upgrade prompt.

What it runs, and what it does not do

ThumbGate Desktop asks for full access for one reason: to run one read-only command in the project folder you pick.

npx thumbgate desktop-snapshot --json

That command reads the same local files as thumbgate stats and thumbgate explore and prints one JSON document with a fixed schema, thumbgate.desktop-snapshot/v1. On older ThumbGate releases the app falls back to those two commands and shows counts without the list of recent blocks.

  • It does not write files, capture feedback, or add or remove rules.
  • It does not enforce anything. Blocking still happens in ThumbGate's PreToolUse hook, whether the app is open or not.
  • It does not send your data anywhere. The snapshot is read on your computer and shown in the app's window.
  • It checks once a minute, not in real time, so a notification can come up to a minute after the block.

Try it

  1. Install ThumbGate in a project: npx thumbgate init.
  2. Update Claude for Mac or Claude for Windows to 6.28899.0 or later.
  3. Ask Claude to publish the page in adapters/claude-desktop-app as an artifact with the desktop capability, then choose Install as app. Building it in your own account matters: Claude generally allows full access only for apps written inside your own organization.
  4. Open ThumbGate Desktop, pick your project folder, and allow access. Turn on the menu bar item and alerts if you want them.
