ThumbGate

ThumbGate for students of the free Udemy course

This page goes with the course Claude Code + ThumbGate: Understand the Gate and Its Limits. The course explains what the ThumbGate gate checks before an AI coding agent's tool call runs, and where that check does not reach.

Install it free

One command, in the project you want to protect:

THUMBGATE_INSTALL_SOURCE=udemy npx thumbgate init

The first part only records that you came from the course, so the course author can see whether the course leads to installs. Leave it off and ThumbGate works the same. You can also turn telemetry off with THUMBGATE_NO_TELEMETRY=1.
