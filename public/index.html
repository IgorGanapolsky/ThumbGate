Product loop

One correction becomes a pre-action gate.

ThumbGate is deliberately small: capture feedback, generate a prevention rule, and check the next tool call before execution.

1

Install locally

Run npx thumbgate init and wire the hook into your AI coding agent workflow.

2

Thumbs-down once

When an agent reaches for a bad action, record the correction as structured feedback.

3

Block the repeat

The next matching tool call is stopped before it mutates files, branches, databases, or config.

Why now

Repeated agent mistakes are getting more expensive.

Frontier model calls, long-context retries, and autonomous edits all raise the cost of letting the same failure rerun. ThumbGate focuses on the narrow control point you can verify: the next tool call.

Token and cash pressure

Every repeated bad tool call burns context, model output, and human review time. Blocking the repeat is cheaper than explaining it again.

Versioned proof

Teams need a record of what was blocked, why it was blocked, and which rule created the decision. The proof has to survive the session.

Data-layer accountability

Runtime sandboxes help, but teams still need local rules for repo, file, branch, secret, and production-data boundaries.

Editor coverage without fake extensions

VS Code works when you run an MCP-compatible agent inside it. ThumbGate names the supported agent path instead of pretending every editor has a native extension.

Honest scope

What it actually blocks.

ThumbGate catches recognizable tool calls and repeated patterns. It does not magically understand every bad judgment an AI agent could make.

git push --force origin main

Rule: never force-push protected branches.

rm -rf .git

Rule: never delete repository history.

DROP TABLE production_users;

Rule: never run destructive SQL against production targets.

sed -i ... .env

Rule: never rewrite secrets or environment files without explicit approval.

git reset --hard

Rule: never discard uncommitted user work.

npm publish --access public

Rule: never publish a package without release verification.

This is a gate for repeated, detectable actions. Keep tests, code review, and human approval for ambiguous product decisions.

I built ThumbGate because instruction files are advice, not enforcement. CLAUDE.md and Skills help agents remember what you prefer. ThumbGate sits before the tool call and turns the correction into something the next run has to obey.

Igor Ganapolsky, founder of ThumbGate
Platform fit

Enforcement is the missing layer in AI orchestration.

Broad orchestration platforms decide what should happen next. ThumbGate decides what is allowed to execute at the tool boundary, so the last mile is not left to memory, prompts, or another dashboard.
