Local-first enforcement

No LLM on the block/allow path. Deterministic rules first; local semantic recall only when needed.

Feedback → rules

Thumbs-down becomes a reviewable lesson, then a prevention rule that fires before the next tool call.

Multi-agent surface

One gate layer across Claude Code, Cursor, Codex, Gemini, Amp, Cline, OpenCode, and MCP.

Failure recovery

Stable row IDs, pending-index retry, checkpointed re-index, stale-version retirement, provider timeouts, and one structured-output repair.

Cost control

Embedding reuse, fixed candidate pools, exact-query rewrite bypass, prompt token budgets, capped retries, and no agent-controlled retrieval loop.

Measured ranking

24 seeded cross-domain cases gate Recall@10, MRR@10, nDCG@10, Precision@5, scope leakage, and stale hits.

Index truth

When an ANN index exists, a bounded probe compares it with exhaustive LanceDB results. Exact-only tables are labeled exact_only, never reported as perfect ANN recall.

Replayable fault proof

Three seeded scenarios inject an embedding interruption, vector outage, and repeated invalid model output. Named invariants, fault position, scenario order, and a replay command are retained in the proof artifact.
