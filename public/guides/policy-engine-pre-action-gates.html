The buyer objection

"We already have a policy engine." Good. ThumbGate should sit underneath it, not compete with it. Policy engines answer whether an action is compliant. ThumbGate makes that answer operational at the exact moment an AI agent is about to touch a real system.

Policy reasoning vs execution enforcement

Layer What it does Failure if used alone
Policy engine Evaluates a rule, ontology, risk model, or compliance policy. The agent can still execute if the decision is not wired into the tool boundary.
Audit log Records what the agent did and why it was allowed or denied. The record arrives after the risky action may already have run.
ThumbGate Intercepts the concrete action locally before shell, file, MCP, deploy, browser, or API execution. It needs policy input for teams that already maintain centralized governance models.

Adapter contract

The adapter normalizes common policy-engine outputs into ThumbGate's enforcement shape.

{
  "decision": "block",
  "reason": "off-scope network egress",
  "policyId": "egress-001",
  "evidence": [
    { "ruleId": "egress-001", "reason": "curl to unknown host" }
  ]
}

ThumbGate then treats that as a pre-action decision. If the policy says block, the wrapped tool does not execute. If the policy says allow but a local thumbs-down rule catches a repeated mistake, ThumbGate can still hard-block locally.

FAQ

Does ThumbGate replace a policy engine?

No. A policy engine decides whether an action is allowed. ThumbGate enforces that decision before the agent executes a shell, file, MCP, browser, deploy, or API action.

Can ThumbGate use Guardian SDK, Ethicore, OPA, or Bedrock Guardrails decisions?

Yes. The policy-engine adapter normalizes allow, block, and approval-required outputs from external policy engines, then applies local pre-action gates before execution.

Why not just log policy violations after the run?

Post-run logging proves what happened after damage is possible. Pre-action gates stop the risky action before it runs and preserve the evidence for audit.
