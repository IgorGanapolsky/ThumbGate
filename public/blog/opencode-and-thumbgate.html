OpenCode and ThumbGate

2026-11-11 · guide

Google's Decisions announcement lists OpenCode among the launch integrations. ThumbGate is not one of those integrations. ThumbGate has its own OpenCode adapter, and that adapter does not call Gemini.

Install

npx thumbgate init --agent opencode

Init reads adapters/opencode/opencode.json from the installed package and merges the mcp.thumbgate entry into ~/.config/opencode/opencode.json. The file shipped in 1.39.1 starts the server with this command:

npx --yes --package thumbgate@1.39.1 thumbgate serve

If ~/.config/opencode/opencode.json is already there and does not parse as JSON, init stops, sets a failing exit code, and leaves the file as it was. Fix or move that file, then run init again. Restart OpenCode so it loads the MCP server.

What the check can do

OpenCode's row in the install table is advisory MCP gate_check. OpenCode has no ThumbGate hook. OpenCode decides whether to honor the MCP result. When it does not, the tool call runs.

A hard stop before the tool runs is the hook path, on Claude Code, Codex, Gemini CLI, and ForgeCode:

npx thumbgate init --agent claude-code
npx thumbgate init --agent codex
npx thumbgate init --agent gemini
npx thumbgate init --agent forge

Any other MCP agent can run npx thumbgate serve. That is the same advisory check.

Why a score is not a gate: ThumbGate enforces the tool call.
