ThumbGate enforces the tool call. Gemini Decisions scores it.

2026-11-11 · engineering

Google published Gemini Decisions today. It returns a confidence score for a fixed question about one input. ThumbGate is the check that runs before the tool call, writes the verdict to the local lesson record, and can turn a thumbs-down into the next rule.

What Google shipped

The announcement is Gemini Decisions. Read Google's post for Google's description. A score from that API does not, by itself, stop a tool call. Something in the agent harness has to refuse the call before it runs.

What ThumbGate ships today

The install table is the contract. npx thumbgate init wires a hard hook on four agents. On those agents the hook sees the proposed tool call and returns the verdict before the tool runs. The shipped hook does not call a language model. The same call gets the same verdict. That path is the one in No LLM in the gate.

Cursor, Cline, and OpenCode do not get that hook. They can ask gate_check over MCP. The tool still runs unless that client honors the result. Any other MCP agent can run npx thumbgate serve and gets the same advisory check.

Secrets stay denied. A thumbs-down is stored with the local lesson record on the machine, and a repeated rejection can become a prevention rule. The record is that local store.

Separate from today's gate

An opt-in Gemini Decisions check is in review: this pull request. It is not what runs today.

OpenCode

Google's launch list names OpenCode. ThumbGate's OpenCode adapter does not call Gemini. It registers a local MCP server. The setup steps are in OpenCode and ThumbGate.
