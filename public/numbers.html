Methodology

Where the numbers come from. This page is regenerated from local scripts — no survey data, no hand-edited figures, no third-party attribution. Every number on this page is produced by code in the public ThumbGate repo.

  • Configured checks — union of shipped default rules and the auto-promotion ledger. This is inventory, not proof that the check fired.
  • Actions blocked/warned — recorded intervention counts from gate occurrence data. These are the evidence counters.
  • Hours saved — conservative 15-minute/incident estimate, shown only as a function of recorded block/warn counts.
  • Dollars saved — blended per-call token estimate (2k input + 600 output) × recorded blocks × 2026-04-15 Anthropic + OpenAI list prices. See scripts/token-savings.js for the full price snapshot.
  • Bayes error rate — shown only when the feedback sample contains both safe and harmful outcomes. One-class samples are reported as n/a.

Last auto-promotion: none. Regenerated on every release via npm run numbers:generate and on a weekly cadence.
