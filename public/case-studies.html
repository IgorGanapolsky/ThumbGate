Class: Destructive git operation Agent: Claude Code Outcome: Blocked

Force-push to main during a "fix tests" session

A solo developer asked Claude Code to fix a failing test. After a series of merge-resolution attempts, the agent proposed git push --force origin main to "clean up the branch state." Without ThumbGate, this would have overwritten three teammates' unpushed work on a shared repo.

$ git push --force origin main
⛔ ThumbGate Pre-Action Check fired
   Rule: never-force-push-to-protected-branch
   Pattern: git push.*--force.*\b(main|master|production|release)
   Verdict: BLOCK
   Suggested alternative: open a PR with the cleaned history; let CI verify.

Rule provenance: Generated from a thumbs-down event in a different user's session two weeks earlier. Lesson promoted to a portable PreToolUse rule. Distributed to all installs via the default check pack.

Class: Secret exposure Agent: Cursor Outcome: Blocked

Agent attempted to commit .env containing live API keys

A developer asked Cursor to "add the environment config to the repo so deploys work." The agent read .env, recognized it as configuration, and proposed staging it for commit. The file contained a live Stripe key and a Resend API key.

$ git add .env
⛔ ThumbGate Pre-Action Check fired
   Rule: never-stage-dotenv
   Pattern: git add.*\b\.env(\b|\.local|\.production)
   Verdict: BLOCK
   Suggested alternative: add .env to .gitignore; use a secrets manager.

Counterfactual cost: A leaked Stripe key in a public repo is a credential-rotation incident plus a GitGuardian / TruffleHog notification. Median cleanup time across reported incidents is 4-6 engineering hours plus the customer-comms cost if the keys touched payment flows.

Class: Hallucinated package install Agent: Generic MCP-compatible agent Outcome: Blocked

Agent attempted to install a fabricated npm package

An agent recommended a package called react-stream-validator for input handling. The package does not exist on the public npm registry; it was hallucinated as a likely-sounding name based on neighboring packages. A typosquatter could publish this exact name tomorrow with a postinstall payload.

$ npm install react-stream-validator
⛔ ThumbGate Pre-Action Check fired
   Rule: never-install-unverified-npm-package
   Check: npm registry probe → 404 (package does not exist)
   Verdict: BLOCK
   Suggested alternative: ask the agent to cite a real package from npm. zod, yup, joi all exist.

Why this matters: Slopsquatting (typosquatted packages targeting AI-hallucinated names) has been documented as an active supply-chain attack vector since 2024. ThumbGate's PreToolUse check verifies the package exists on npm before the install command reaches the registry.
