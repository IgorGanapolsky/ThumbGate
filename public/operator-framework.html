Operator Framework

ThumbGate, deployed and operated for your agents.

ThumbGate is a pre-action firewall for AI coding agents. It runs in the PreToolUse hook and evaluates each proposed tool call before it executes. The Operator Framework is how we install it, configure it for the failures you actually have, and keep it working, for your own agents or your clients'.

✓Checked before it runs: risky tool calls are caught at the hook, before the agent acts. A prompt doesn't do that.
✓Safe defaults: detected secret leaks and ThumbGate self-disable commands are hard-blocked by default.
✓Learns from feedback: repeated, concrete failures become local prevention rules. No model retraining.
✓Local-first: no cloud is required for the enforcement path.
Default verdicts (from the open-source README)
VerdictDefault behavior
⛔ Hard-blockDetected secret leaks; commands that kill the gate process or enable its bypass override
👎 Warn + logrm -rf, git push --force, fetch-and-run, direct guardrail edits. These become hard denies with THUMBGATE_STRICT_ENFORCEMENT=1
👍 AllowEverything else

Works with Claude Code, Cursor, Codex, Gemini CLI, Amp, Cline, OpenCode, and other MCP agents. ThumbGate does not update model weights. It intercepts tool calls at runtime. Source: github.com/IgorGanapolsky/ThumbGate. Evidence: verification evidence · proof reports.
