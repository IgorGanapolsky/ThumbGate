# Nous Research Hermes Agent + ThumbGate

Nous Research's **hermes-agent** introduces persistent, self-improving autonomous agents that run across multiple messaging channels:

- Operates directly in Discord, Slack, Telegram, Signal, WhatsApp, and CLI.
- Self-evaluates completed tasks and extracts reusable reasoning patterns.
- Writes and updates dynamic "skills" in Markdown format to improve future runs.
- Model-agnostic, supporting local inference (Ollama) and cloud APIs (OpenRouter).

While these autonomous capabilities are powerful, they present unique security, compliance, and stability challenges: message spam, credentials leaks in public chat channels, and infinite skill rewrite loops.

**ThumbGate provides the missing pre-action governance layer to secure and stabilize Hermes Agent operations.**

---

## Why High-ROI for ThumbGate

- **Multi-Channel Guardrails:** Intercepts outgoing messaging tool calls before they post API keys, auth tokens, or unreviewed text to public channels.
- **Skill Synthesis Constraints:** Scans new Markdown skills generated by the agent to ensure they do not conflict with or bypass active ThumbGate prevention rules.
- **Loop Mitigation:** Tracks and halts infinite self-improvement loops where the agent repeatedly rewrites the same skills without resolving the core task.
- **Harvest DPO Datasets:** Translates thumbs-up/down signals on Hermes tasks into structured Direct Preference Optimization (DPO) pairs, ready for fine-tuning Nous models.

## Setup & Integration

### 1. Wire MCP & Hooks
Merge the corresponding template in `adapters/hermes/` into your agent's configuration:
*   For Claude Code: Merge [adapters/hermes/.mcp.json](file:///Users/igorganapolsky/workspace/git/igor/ThumbGate/repo/adapters/hermes/.mcp.json).
*   For Codex: Merge [adapters/hermes/config.toml](file:///Users/igorganapolsky/workspace/git/igor/ThumbGate/repo/adapters/hermes/config.toml).
*   For OpenCode: Merge [adapters/hermes/opencode.json](file:///Users/igorganapolsky/workspace/git/igor/ThumbGate/repo/adapters/hermes/opencode.json).

### 2. Enable Gating Rules
To activate the new templates, enable them in your local `.thumbgate/rules.json` or run:
```bash
npx thumbgate gate-templates --enable block-unauthorized-multi-channel-posts
```

### 3. Capture Feedback for DPO
When running evaluations on Hermes tasks, capture structured feedback with relevant tags. This allows you to generate DPO training sets for model tuning later:

```bash
npx thumbgate capture --signal down --context "Hermes agent leaked raw API credentials in a Telegram reply" --tags "hermes,telegram,credentials-leak,security-failure"
```

To export the training pairs:
```bash
npx thumbgate export-dpo --output ./hermes-dpo-dataset.json
```
